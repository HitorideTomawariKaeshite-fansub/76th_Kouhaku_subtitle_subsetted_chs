本版字幕渲染效果以 mpv 播放器为基准进行调校，为确保最佳观赏体验，建议使用 mpv、其衍生版本或以 mpv 为核心引擎的播放器，不推荐使用 PotPlayer、MPC、VLC 等其他播放器。

本字幕采用子集化封装，无需额外安装字体即可正确渲染。

此仓库只提供字幕文件，视频文件请自行使用合法方式获得。

特别提示：综合台 1080i ts 档使用外挂字幕时如果出现字幕显示异常（如字体变瘦/变扁），请确保使用 mpv 播放器，并且检查 mpv 播放器的 mpv.conf 配置文件里面的 "blend-subtitles" 参数的值，确保其不是 "video"，参数的值设置为 "no" 或者 "yes" 都可以，因为 video 模式会将字幕直接烧录进视频的原始色彩平面，对于非正方形像素的视频（例如 1440x1080 的综合台 1080i ts 档），mpv 会在渲染字幕后才进行拉伸修正，而 no 或 yes 模式能确保字幕在视频画面拉伸修正之后才进行渲染，从而保证字幕显示正确。
